Pruebas de la API de notificaciones

Ingresá tu API Key en Authorize. Usá Try it out y después Execute para probar cada operación.

  1. Verificá tu clave con GET /avisos.
  2. Creá un aviso con POST /avisos. Indicá un correo propio y una Idempotency-Key nueva para cada aviso diferente.
  3. Copiá el id recibido y consultá GET /avisos/{id}. Un resultado 202 significa aceptado, el envío se procesa después.

Los envíos son reales. Cada grupo debe usar su propia clave. La página no incluye credenciales.
